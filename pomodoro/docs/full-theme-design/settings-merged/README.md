# BOOST 공용 설정 화면 — 숫자 + 게이지 합치기 (시안 3개)

설정 화면은 모든 테마가 하나(01 SAND 설정)를 쓴다. 지금은 왼쪽 큰 숫자(FOCUS 25 / REST 05)와 오른쪽 세로 막대가 따로 있다.
이 폴더는 **숫자와 게이지를 한 요소로 합친** 시안 3개다. SAND 시각 언어 그대로: 검정 바탕, 집중 `#FF4B4B`, 휴식 `#3DDC84`, 흰 글자 + 검정 외곽선(text-shadow).
모두 CSS(div 높이·색, text)만 쓴다 — 이미지 0.

## ✅ 확정: A-final (사용자 선택 A TWIN TUBES, 아래 줄만 변경) — `A-final/`

- **관을 최대로**: 관 안쪽 y 68~420(352px, 전보다 +32px). 위는 끌기 여백 64 바로 아래, 아래는 아래 줄 터치 영역(432~) 바로 위.
  **집중 29.33 px/칸**(전 26.7), **휴식 11.73 px/칸**(전 10.7). 공식 `k = clamp(ceil((420 − y) / px), 1, 최대)`.

  겹침 없음, x<30 없음, 끌기 위 끝 y 64, 가장 작은 영역 repeat 80×68(≥48) — check `ok: true`.
- **안전 영역**(`touch-zones.json` safeArea): 둥근 화면 안쪽까지 최소 거리 — 영역 focus/rest 36.9px, start 8px,

## 공통 조작 규칙 (THERMO 와 같음)

- **세로만.** 손가락이 12px 움직이면 축 고정. 세로로 고정되면 그 영역의 끌기, 가로로 고정되면 아무 일도 안 한다(좌우 스와이프는 앱이 꺼지므로 앱은 좌우 제스처를 쓰지 않음).
- **탭** = 축 고정 없이 손을 떼고 총 움직임 ≤ 40px.
- **x < 30 터치 없음**(뒤로 가기 스와이프 자리). 영역은 서로 겹치지 않고, 모서리가 둥근 화면 안, 가장 작은 변 ≥ 48px — 세 시안 모두 `touch-zones.json` check `ok: true`.
- **± 버튼은 뺐다.** 탭과 끌기로 충분하고(아래 정밀도), 버튼 자리를 게이지가 차지해 숫자가 커졌다.
- **위쪽 여백: 끌기 영역은 y ≥ 64.** 위 가장자리에서 시작하는 끌기는 시스템 풀다운(제어 센터)과 겹칠 수 있다. 64px 는 화면 높이의 12%,
  모서리 반경 80 의 둥근 부분 안쪽이다. 최댓값 칸도 y 72~100 에 있어 최대로 올리려고 가장자리까지 손을 올릴 필요가 없고, 끌다가 64 위로 나가도
  최대로 고정된 채 끌기가 이어진다. 시스템 풀다운이 실제로 몇 px 에서 시작하는지는 미확인 [PLACEHOLDER: 기기에서 위 가장자리 끌기 시험].
- 아래 줄(세 시안 공통): REPEAT 토글 `[40, 412, 200, 468]`, START `[204, 408, 392, 484]`.

## 시안별 터치

### A TWIN TUBES — 절대 지정
  - `focusGauge` [40, 64, 212, 404]
  - `restGauge` [220, 64, 392, 404]
  - `repeat` [40, 412, 200, 468]
  - `start` [204, 408, 392, 484]
- 관 안쪽 y 72~392 (320px). 집중 12칸 = **26.7 px/칸**, 휴식 30칸 = **10.7 px/칸**. `k = clamp(ceil((392 − y) / px), 1, 최대)`, 집중 값 = 5k.
- 탭 = 그 높이로 바로, 끌기 = 손가락 높이를 따라감(칸에 스냅).
- 약점: 휴식 10.7 px/칸은 지금 THERMO 막대(10 px)와 거의 같아 정확히 맞추기 어렵다(그래서 THERMO 에 ±1 탭을 붙였었다). 또 값 35~55 근처에서는 손가락이 숫자를 가린다.

### B SPLIT SAND — 끌기는 절대, 탭은 수위선 기준 ±1
  - `focusGauge` [40, 64, 212, 404]
  - `restGauge` [220, 64, 392, 404]
  - `repeat` [40, 412, 200, 468]
  - `start` [204, 408, 392, 484]
- 채움 영역 y 72~400 (328px). 집중 **27.3 px/칸**, 휴식 **10.9 px/칸**. 끌기: `k = clamp(ceil((400 − y) / px), 1, 최대)` — 수위선이 손가락을 따라온다.
- 정밀: 수위선(채움 윗면, `400 − round(328 × k / 최대)`)보다 위를 탭 = +1, 아래를 탭 = −1. 대충 끌어 놓고 탭으로 1칸씩 맞춘다.
- 숫자는 수위선 바로 위(공간 없으면 바로 아래)에 붙어 움직여 "값 = 높이"가 바로 읽힌다. 바탕이 화면 가장자리까지 가서 SAND 와 가장 비슷하다.
- 약점: 끌 때 손가락이 수위선 위 숫자 바로 아래에 있어 일부를 가릴 수 있다. 휴식 절대 끌기는 10.9 px/칸이라 탭 보정이 필요하다.

### C STACKED — 상대 끌기(문지르기) + 반 탭 ±1
  - `focusBlock` [40, 64, 392, 226]
  - `restBlock` [40, 232, 392, 394]
  - `repeat` [40, 412, 200, 468]
  - `start` [204, 408, 392, 484]
- 끌기는 손가락 위치와 상관없이 **움직인 거리**로 값이 바뀐다: `k = clamp(k0 + round((y0 − y) / px), 1, 최대)`, 위로 = 증가.
  집중 **26 px/칸**(5→60 은 286px), 휴식 **12 px/칸**(1→30 은 348px — 모자라면 한 번 더 문지르면 이어짐). 비율은 바꾸기 쉽다(`Stacked.PX`).
- 탭: 블록 위쪽 반 = +1, 아래쪽 반 = −1 (나누는 선: 집중 y 145, 휴식 y 313). 오른쪽의 작은 ▲▼ 는 이걸 알려 주는 표시(div 막대로 만든 삼각형).
- 숫자는 블록 왼쪽, 문지르기는 블록 어디서나 되므로 오른쪽을 문지르면 숫자를 가리지 않는다. 블록 높이가 144px 라 채움은 "대략의 비율"만 보여 준다.
- 축 고정 12px 와 휴식 12 px/칸이 같아, 세로로 고정되는 순간 1칸 움직인다(의도대로 느껴질 것으로 봄 — 실기기 확인 [PLACEHOLDER]).

## 추천 (선택 전 의견 — 사용자는 A 를 골랐고 확정안은 위 A-final)

**C STACKED.** 휴식 30칸을 고르기가 셋 중 가장 쉽다(상대 끌기 12 px/칸 + 1칸 탭). 손가락이 숫자를 가리지 않고, 위아래 두 영역이라 손이 닿는 자리가 넓다.
SAND 느낌(꽉 찬 색면)을 더 원하면 **B SPLIT SAND** 가 차선: 생김새는 가장 SAND 답고, 대충 끌고 수위선 위/아래 탭으로 맞추면 된다.
A 는 가장 단순하지만 휴식 정밀도가 지금 THERMO 막대와 같은 문제라 추천하지 않는다.
